# Снимок «классического» режима (2026-10-25)

Режим, который пользователь протестировал в шлеме и попросил сохранить как дополнительный:
третье лицо, камера игры + голова, прицел взглядом, контроллеры = геймпад Xbox.

- Рабочая копия: `BinariesVR_Classic\` (запуск: `Запуск VR (классика).bat`). НЕ ДОРАБАТЫВАТЬ без просьбы пользователя.
- `xinput1_3.dll` здесь — ровно та сборка (13:44), в которую играл пользователь; `twfcvr.ini` — её настройки.
- `src\` — исходники на момент снимка. Они чуть новее DLL: в них уже есть экспериментальные split-хуки и хук начала кадра, неактивные по умолчанию.
  Чтобы пересобрать точную классику, достаточно не включать эти отладочные команды.

Известные проблемы классики (по отзыву пользователя): низкое разрешение; меню во весь обзор шлема, а не на экране вдали.
